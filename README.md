# Haunted Graph Kit

A static web site that places text and images as nodes in 3D space and connects them. Two apps are planned on one shared core. At this stage the site holds only placeholder pages.

Public URL: [https://seimu1207.github.io/SpatialCore/](https://seimu1207.github.io/SpatialCore/)

| App | Path | Link |
|---|---|---|
| Ghost Mansion | `/ghost-mansion/` | [https://seimu1207.github.io/SpatialCore/ghost-mansion/](https://seimu1207.github.io/SpatialCore/ghost-mansion/) |
| Moodwalk | `/moodwalk/` | [https://seimu1207.github.io/SpatialCore/moodwalk/](https://seimu1207.github.io/SpatialCore/moodwalk/) |

## Run it locally

Node.js 26.13.0 (the version in `.nvmrc`).

```
npm ci
```

```
npm run build
```

```
npm test
```
